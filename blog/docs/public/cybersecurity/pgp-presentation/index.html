What is PGP?

  • Every user has two keys: a public key and a private key.
  • The public key is shared. Anyone can use it to encrypt a message for you.
  • The private key stays with you. Only it can decrypt that message.
  • You sign with your private key, so people know the message is really from you.

PGP was created in 1991. Today it is an open standard, OpenPGP (RFC 9580).

How CipherChat uses PGP

1. Create an account
2. The browser creates your keys
3. Send a message or file, encrypted and signed
4. The receiver decrypts it and sees "Verified"

Only the public key is sent to the server. The private key never leaves the browser.

The server only ever sees scrambled text.It stores and delivers messages, but it cannot read them.

Security highlights

End-to-end encryption: messages and files are encrypted in the sender's browser.

Zero-knowledge server: it never sees plaintext, private keys or passphrases.

Signatures: the receiver sees "Verified" when a message really came from the sender.

Fingerprints: users can compare them to check that no key was swapped.
